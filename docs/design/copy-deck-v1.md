# Copy Deck v1 (用户端全站)

- Project: 工程造价规范检索助手
- Scope: `/` `/search` `/search/[chunkId]` `/qa` `/trial` + 全局导航/页脚/CTA
- Date: 2026-03-17
- Principle: 专业、明确、可追溯、不过度营销

## 1. 文案语气与术语规范

## 1.1 语气规则

1. 使用“动作 + 结果”句式，避免空泛口号。
2. 对风险边界直接说明，不使用模糊承诺。
3. 错误提示包含可执行下一步。

## 1.2 统一术语

1. 规范：指标准/规范文档。
2. 条款：指章节中的具体文本片段。
3. 依据引用：回答中关联的来源证据。
4. 试用申请：企业咨询与试用入口。

## 2. 全局文案

## 2.1 导航

1. 首页
2. 规范检索
3. 问规则
4. 试用申请
5. 后台（仅内部）

## 2.2 全局 CTA

- 主文案：企业可申请内部试用，支持项目资料专项分析与本地部署咨询。
- 主按钮：申请试用
- 次按钮：进入规范检索

## 2.3 页脚

- 行 1：工程造价规范检索助手 · MVP
- 行 2：定位：查规范、查依据、问规则，并承接企业内部试用咨询。

## 3. 页面文案清单

## 3.1 首页 `/`

- Hero 标记：工程造价规范检索与问答平台
- 主标题：查规范 · 查依据 · 问规则 · 申请试用
- 说明：面向造价师、预算员、造价咨询团队，快速定位规范条款与计价依据。
- 输入占位：输入规范名称、编号或关键词，例如：GB 50500、工程变更、结算审核
- 主按钮：进入规范检索
- 次入口：去问规则 / 申请试用
- 能力区标题：核心能力
- 场景区标题：适用场景
- 风险区标题：风险提示

## 3.2 规范检索页 `/search`

- 页面标题：查规范 / 查依据
- 页面说明：支持按规范名称、编号、条文关键词检索，并定位章节与页码。
- 检索占位：输入规范名称、编号或关键词，例如：GB 50500、工程变更、结算审核
- 筛选标签：分类筛选
- 统计文案（有结果）：共 {total} 条结果
- 统计文案（加载中）：正在检索...
- 空态标题：未检索到匹配结果
- 空态说明：建议尝试：1) 缩短关键词 2) 使用规范编号 3) 切换分类
- 错误态：检索失败，请检查网络后重试。
- 详情按钮：查看详情

## 3.3 检索详情页 `/search/[chunkId]`

- 页面标题：条款详情
- 返回按钮：返回检索页
- 描述模板：查看 {documentCode} 的条款原文定位信息与章节内容。
- 标签：发布日期：{date}
- 字段：条款章节：{chapterPath 或 未标注章节}
- 字段：页码：{page 或 未标注} · 排序：{sortOrder}
- 字段：版本：{version}
- 区块标题：原文内容
- 来源字段：来源标识：{source}
- 缺失元数据标题：条款详情不存在

## 3.4 问规则页 `/qa`

- 页面标题：问规则
- 页面说明：先检索依据，再生成回答。回答附引用，便于复核。
- 风险提示：回答仅供参考，具体以合同、补充协议、项目资料为准。
- 文本域占位：请输入工程造价相关问题，例如：工程变更引起的价款调整如何处理？
- 主按钮（默认）：提交问题
- 主按钮（加载）：正在生成...
- 回答区标题：回答
- 回答区空态：提交问题后将在此处展示回答。
- 引用区标题：依据引用
- 引用区空态：当前无可用引用依据。
- 错误态：问答失败，请稍后重试。

## 3.5 试用页 `/trial`

- 页面标题：试用申请
- 页面说明：面向造价咨询公司与企业成本管理团队，支持内部试用、项目资料专项分析、本地部署咨询。
- 字段：联系人
- 字段：联系方式
- 字段：邮箱
- 字段：需求类型
- 字段：当前反馈 / 需求
- 需求占位：请描述当前项目痛点、资料情况、预期目标。若希望做项目资料专项分析，请写明资料类型和规模。
- 主按钮（默认）：提交内部试用申请
- 主按钮（加载）：提交中...
- 成功反馈：提交成功，我们将尽快与您联系。
- 失败反馈：提交失败，请稍后重试。

## 4. 交互状态文案规范

1. Loading：统一使用“正在 + 动作”，如“正在检索”“正在生成”“提交中...”。
2. Empty：先陈述事实，再给 2-3 条建议动作。
3. Error：简要说明失败 + 提供重试方向，不暴露技术细节。
4. Success：确认结果 + 下一步预期（例如“将尽快联系”）。

## 5. 异常文案修复清单（优先）

以下内容在实现阶段应以本清单替换，避免乱码和占位异常：

1. 文件：`app/search/[chunkId]/page.tsx`
- `title: "鏉℃璇︽儏涓嶅瓨鍦?"` -> `title: "条款详情不存在"`
- ``title: `${chunk.document.title} - 鏉℃璇︽儏` `` -> ``title: `${chunk.document.title} - 条款详情` ``
- `description` 内乱码句 -> `查看 {code} 的条款原文定位信息与章节内容。`
- `鍙戝竷鏃ユ湡` -> `发布日期`
- `绔犺妭瀹氫綅` -> `条款章节`
- `椤电爜` -> `页码`
- `鎺掑簭` -> `排序`
- `鐗堟湰` -> `版本`
- `鍘熸枃鍐呭` -> `原文内容`
- `鏉ユ簮鏍囪瘑` -> `来源标识`

2. 全站占位符统一
- `全部`、`未标注章节`、`未标注` 等缺省词统一，不混用同义表达。
